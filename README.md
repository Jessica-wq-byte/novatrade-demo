# NovaTrade Demo

A free, front-end-only broker/affiliate simulation.

## Important
This project is intentionally a DEMO. It does not process real money, real investments, withdrawals, financial returns, or real affiliate payouts.

## Run locally
Open `index.html` in a browser.

## Free hosting
You can deploy the folder to a static hosting provider such as GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## Notes
- Demo balance starts at $10,000 virtual.
- Investments use virtual funds.
- Returns are simulated locally in the browser.
- The "hourly" simulation runs every 10 seconds for testing, and the interface explicitly identifies it as simulated.
- State is not stored on a server and resets when the page is refreshed.
